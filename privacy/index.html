개인정보 처리방침

시행일 2026년 9월 25일 · 1.7.1 신규 기능 반영
SwipeTrip은 무료로 제공되며 광고·유료 결제가 없는 취향 기반 장소 추천 앱이에요. 장소 둘러보기·저장·일반 방문 기록은 이메일 로그인 없이 이용할 수 있어요. 1.7.1은 이메일 가입 없이 이용하며, 이메일을 통한 기록 보관·복구는 제공하지 않아요. 앱 삭제·기기 변경 시 기록을 복구하지 못할 수 있어요. 아래 신규 기능 관련 내용은 1.7.1에서 해당 기능을 이용할 때 적용돼요.

1 수집하는 개인정보 항목과 방법

이름·전화번호는 요청하지 않아요. 1.7.1 앱에서는 이메일 주소를 입력받지 않아요. 기능을 이용하면서 기기나 서버에서 생성되는 식별자와 아래 기록도 처리해요.

항목수집 방법수집 목적
기기 식별자(임의로 생성한 UUID) 앱을 처음 실행할 때 기기 안에서 자동 생성 — 기기별 이용 기록을 구분하는 용도 스와이프 기록·저장 목록을 기기별로 이어서 보여주기
참여 식별자(1.7.1, 서버가 발급한 임의의 사용자 ID)서버 참여 기능을 이용할 때 이메일 없이도 익명 세션을 만들 수 있어요. 이 익명 계정으로 참여 기록을 구분해요본인의 참여·배지·기록을 구분하고 접근 권한을 확인
방문 기록·배지·선택한 칭호(1.7.1)방문을 기록한 장소·시각, 첫 방문·재방문 및 배지 계산에 필요한 행동 기록을 기기에 보관해요. 일반 방문 기록의 이메일 보관·기기 간 복구는 제공하지 않아요. 위치 확인 방문은 확인 결과를 서버에 기록해요서울 탐험 지도, 방문 이력·행동 배지 표시. 일반 방문과 위치 확인 방문은 구분해요
친구 참여·동행 기록(1.7.1)참여 식별자와 투표방 연결, 장소 결정, 동행 초대·수락·확인, 장소와 시각을 기록해요. 연락처 목록은 수집하지 않아요실제 참여에 따른 배지와 본인·친구의 동행 확인 상태 표시
둘러본 기록(좋아요·별로예요·저장 로그, 취향 선택) 카드를 넘기거나 저장할 때 자동 기록 취향에 맞는 장소를 추천하는 정렬·매칭 품질 개선
듀오 닉네임·투표 결과("같이 골라요" 기능) 초대 링크에 참여할 때 이용자가 직접 입력한 닉네임 + 좋아요 표시한 장소 목록 친구와 함께 고른 장소의 교집합 계산·결과 화면 표시
추천 닉네임('이웃 추천' 등록 시)등록 화면에서 이용자가 직접 입력등록한 장소 카드에 "@닉네임 추천"으로 표시
게시 내용(장소 이름·동네·주소·장소 좌표·활동·방문 시기·추천 이유·좋은 점·기존 장소 연결 제안)등록 화면에서 이용자가 직접 입력검수 후 앱의 발견 카드·장소 상세·이웃 추천 및 친구 초대 웹 화면에 게시
사진(장소 사진 1~3장)이용자가 시스템 사진 선택기에서 고르거나 앱 안에서 바로 찍은 사진만 전송. 위치 등 EXIF 메타데이터는 기기에서 크기를 줄여 다시 저장하는 과정에서 제거된 뒤 서버로 올라가요검수 후 장소 카드의 대표 사진으로 게시
등록 동의 기록(동의 버전·시각)등록 시 저장사진 이용 권리와 게시 동의 확인
방별 참여 식별자·접근 토큰서버가 방 참여용 가명을 발급해요. 접근 토큰은 기기에 보관하고 서버에는 해시만 저장해요본인 투표와 방장의 후보 관리 권한 확인. 이 투표 접근 토큰은 초대 링크에 포함하지 않아요. 1.7.1의 동행 수락용 초대 토큰은 이용자가 공유하는 동행 링크에 포함돼요
처리 이력(방 생성·참여·투표·후보 제외, 추천 제출·승인·보류·숨김 시각)서버 처리 시 자동 기록기능 운영과 오류 확인. 이력에는 사진·추천 본문·정확한 개인 위치를 복제하지 않아요

'이웃 추천' 등록은 만 14세 이상만 할 수 있어요. 만 14세 미만 이용자의 게시물은 수집하지 않으며, 등록된 사실을 알게 되면 지체 없이 내리고 파기해요.

2 위치정보

위치 권한은 "내 주변"이나 1.7.1의 위치 확인 방문을 이용할 때 요청해요. 권한을 허용하지 않아도 장소를 직접 찾고 일반 방문 기록을 남길 수 있어요. 백그라운드에서는 위치를 추적하지 않아요.

다만 정확히 밝히면, "내 주변" 검색을 쓰는 순간에는 현재 위치를 중심으로 한 대략적인 조회 범위(반경 상자)가 근처 장소를 찾기 위해 저희 데이터베이스 서버로 함께 전달돼요. 정밀 좌표는 기기 안에서 사용하고, 서버에는 약 550m 격자에 맞춘 범위를 전송해요. 앱의 위치 이력 테이블에는 저장하지 않지만, 서버의 요청·운영 로그에는 조회 범위와 요청 정보가 남을 수 있어요. 운영 로그 전체의 보관기간을 확인하지 못해 즉시 삭제된다고 약속하지 않아요. "내 주변"과 위치 확인 방문을 사용하지 않고 동네를 직접 골라 둘러보는 경우에는 이용자 기기의 현재 위치를 조회하거나 전송하지 않아요. 장소 등록 시 직접 입력한 주소·좌표는 이용자가 추천하는 장소의 정보로 저장되며 게시될 수 있어요.

위치 확인 방문(1.7.1)은 이용자가 확인 버튼을 누른 순간의 정밀 위도·경도, 위치 정확도와 측정 시각을 서버로 전송해 장소 근처에 있는지 확인해요. 참여 원장에는 원시 GPS 좌표 대신 사용자 ID·장소 ID·확인 시각·확인 기준과 취소 상태를 저장해요. 장소와 방문 시각 자체도 이동에 관한 정보가 될 수 있어요. 요청·운영 로그 전체의 수집 범위와 보관기간은 확인하지 못했으므로 원시 좌표가 모든 서버 로그에서 즉시 삭제된다고 약속하지 않아요.

3 보유·이용 기간과 파기

  • 기기 식별자·둘러본 기록 — 별도로 삭제를 요청하시기 전까지 보관해요. 자동으로 정해진 파기 주기는 아직 없어요. 앱을 지워도 서버에 남은 기록은 자동으로 사라지지 않으니, 지우고 싶으시면 아래 연락처로 요청해 주세요.
  • 익명 참여 계정·참여 원장(1.7.1) — 계정 삭제 전까지 보관하며 현재 자동 파기 주기는 없어요. 앱의 참여 계정 관리 화면에서 계정 삭제를 완료하면 인증 계정과 연결된 방문·배지 근거·동행·보관 기록 및 해당 계정으로 제출한 추천 내용·사진을 삭제해요. 앱 삭제만으로 서버 기록이 삭제되지는 않아요. 일반 방문 기록은 기록 화면에서 개별 취소할 수 있고, 위치 확인 취소는 해당 확인 근거를 무효화해요. 기록 취소와 계정 삭제는 서로 다른 처리예요.
  • 듀오 방·투표 결과 — 초대 링크는 생성 후 72시간이 지나면 만료돼 앱에서 더 이상 열리거나 참여할 수 없어요. 만료된 방의 데이터도 별도 요청 전까지는 서버에 남을 수 있어요.
  • 이웃 추천 게시물(닉네임·내용·사진) — 게시 중에는 보관하고, 삭제 요청을 받으면 지체 없이 게시를 내리고 사진 파일을 파기해요. 검수에서 게시되지 않은 등록물도 삭제 요청 전까지 남을 수 있어요. 현재 자동 파기 주기는 없으며, 삭제 요청은 아래 문의처에서 처리해요.
  • 동의·참여 권한·처리 이력 — 관련 게시물·방의 운영과 문의 확인을 위해 보관해요. 현재 자동 파기 주기는 없으며, 본인 확인이 가능한 삭제 요청은 아래 연락처에서 처리해요. 방이 만료되면 토큰으로 방에 접근할 수 없어요.
  • 요청을 받으면 지체 없이 파기해요.

4 제3자 제공

수집한 정보를 광고주·데이터 판매업체에 판매하거나 광고 목적으로 제공하지 않아요. 배지 모음은 기본적으로 본인에게만 보여요. 이용자가 배지와 공유 대상을 직접 선택하면 선택한 배지가 외부 앱의 공유 화면으로 전달돼요. 배지 공유 카드에는 방문 장소·날짜·친구 정보를 자동으로 넣지 않아요. 공개 추천 게시물과 투표·동행방 참여 정보는 위에 안내한 기능의 공개 범위에 따라 보여요.

5 처리 위탁 및 국외 이전

앱 데이터는 데이터베이스 호스팅 서비스인 Supabase, Inc.의 서버(리전: 일본, ap-northeast-1)에 저장·처리돼요. 이용자가 앱을 사용하는 동안 네트워크를 통해 실시간으로 전송·저장되며, 별도의 동의 없이 서비스 제공을 위한 처리위탁으로 진행해요(개인정보보호법 제28조의8).

이전 항목이전받는 자이전 국가이전 일시·방법이용 목적보유 기간
기기 식별자, 둘러본 기록, 듀오 닉네임·투표 결과·방별 식별자·토큰 해시·처리 이력, 이웃 추천 게시물(닉네임·내용·장소 주소와 좌표·사진) 및 동의 기록. 1.7.1의 참여 식별자, 방문·배지·선택 칭호·동행·보관 기록, 위치 확인 요청 시 정밀 위치·정확도·측정 시각 Supabase, Inc. 일본(도쿄) 앱 이용 시 네트워크를 통해 수시로 전송·저장 데이터베이스 호스팅·인증·사진 저장(서비스 운영에 필요한 처리·조회) 위 3번 항목과 동일

6 이용자의 권리

1.7.1의 익명 참여 계정은 앱의 참여 계정 관리 화면에서 삭제할 수 있어요. 계정 삭제는 인증 계정·참여 원장과 해당 계정에 연결된 추천 내용·사진을 삭제해요. 이메일 가입 없이 현재 기기의 참여 계정을 삭제할 수 있어요. 계정에 연결되지 않은 과거 기기 식별자의 둘러본 기록·추천 게시물과 다른 참여자가 함께 이용하는 기존 투표방 전체를 일괄 삭제하지는 않아요. 본인 확인이 필요한 과거 기록·게시물의 열람·삭제는 아래 연락처로 요청해 주세요. 앱을 삭제하거나 기기를 바꿔 익명 계정의 접근 정보를 잃은 경우 자동 복구를 제공하지 않아요. 본인 확인이 가능한 기록의 열람·삭제는 문의로 요청할 수 있어요. 문의 내용을 확인한 뒤 처리해 드려요.
